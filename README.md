# GeoQuiz Nations

App educativa per lo studio dei Paesi del mondo con quiz.

## Funzionalità
- Ricerca Paesi
- Schede informative con bandiere
- Quiz a risposta multipla
- Statistiche e cronologia

## Setup
```bash
dotnet restore
dotnet build
```

## Tech Stack
- .NET MAUI
- CommunityToolkit.Mvvm
- REST Countries API
